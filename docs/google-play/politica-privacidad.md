# Política de privacidad de Taller de Cerámica

Vigente desde el 6 de agosto de 2026.

Taller de Cerámica es una aplicación de organización para talleres administrada por Nahuel Apps. Esta política explica qué información utiliza la aplicación y cómo se protege.

## Información utilizada

La aplicación puede guardar nombres y teléfonos de alumnos, grupos, asistencias, clases pendientes, modelos, fotografías, feriados, recordatorios y preferencias del taller.

Todos estos datos se guardan localmente en el dispositivo. Nahuel Apps no recibe esta información en servidores propios.

## Contactos

El acceso a contactos se solicita únicamente para que el usuario pueda elegir una persona y copiar su nombre y teléfono al registro de un alumno. La aplicación no publica la agenda, no la usa con fines publicitarios y no la envía a Nahuel Apps.

También es posible cargar el nombre y el teléfono manualmente sin utilizar la agenda del dispositivo.

## Cámara y fotografías

La cámara y el selector de imágenes se utilizan únicamente cuando el usuario decide agregar fotografías a un modelo de cerámica. Las imágenes elegidas se guardan junto con los datos locales de la aplicación.

## Notificaciones

Las notificaciones son opcionales y se programan localmente para recordar clases y copias de seguridad. Nahuel Apps no utiliza notificaciones remotas ni recibe identificadores para enviar mensajes.

## Copias de seguridad y archivos

La aplicación puede crear una copia de seguridad cuando el usuario lo solicita. Android muestra el selector del sistema para que el usuario decida dónde guardar o compartir el archivo. Esa acción puede enviar la copia a un servicio elegido por el usuario, por ejemplo Google Drive.

Las copias pueden contener nombres, teléfonos, agenda, fotografías y demás información del taller. El usuario es responsable de guardarlas en una ubicación privada y de eliminarlas del servicio elegido cuando ya no las necesite.

## Recopilación, venta y publicidad

Nahuel Apps no recopila, vende ni comparte los datos del usuario. La aplicación no contiene publicidad, seguimiento, analítica, creación de cuentas ni inicio de sesión.

## Conservación y eliminación

Los datos permanecen en el dispositivo hasta que el usuario los elimina desde la aplicación, restaura otra copia o desinstala la aplicación. Las copias exportadas permanecen bajo el control del usuario y deben eliminarse desde la ubicación donde fueron guardadas.

## Seguridad

La información se mantiene dentro del espacio privado de la aplicación. El usuario debe proteger el acceso a su dispositivo y conservar las copias de seguridad en una ubicación segura.

## Cambios en esta política

Si se agregan funciones que cambian el tratamiento de datos, esta política y la declaración de Seguridad de datos de Google Play serán actualizadas antes de publicar la nueva versión.
